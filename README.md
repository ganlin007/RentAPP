# RentAPP

鸿蒙租房课堂作业。用 DevEco Studio 打开本目录即可。

## 现在做到哪

- 首页：轮播、分类、服务入口和附近房源，数据来自后端。
- 点房源进入详情，可以填写姓名、手机号、日期和备注，提交预约。
- 登录页还没有接到新的请求方式。「想看」仍是占位页，没有预约查询。

## 自己运行

1. 启动租房后端，端口是 `6060`。
2. 打开 `entry/src/main/ets/utils/http.ts`，把 `HOST` 改成你这台电脑上、模拟器能访问到的地址，端口保持 `6060`。
3. 用 DevEco Studio 运行到鸿蒙模拟器。应用需要允许明文 HTTP，工程里已经配好。

接口返回的图片地址如果是 `127.0.0.1`，模拟器打不开，请求结果里会换成上面的 `HOST`。
